# Project Completion History

This is the master chronological index of completed projects and major work initiatives across every application. When a starter kit or project is finished, its folder is archived under the owning application's own `docs/<app-name>/project_history/<kit-name>/`, and a summary entry is appended here.

After completion, use `/kit-complete <app-name> <kit-name> "<summary>"` to archive the kit and log it.
