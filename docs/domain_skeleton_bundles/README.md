# Domain Skeleton Bundles

This directory contains Tier 2 instructions guiding the agent on what parts of the codebase to scan and which documentation to load for specific categories of development tasks.

*   [domain_service_skeleton_instructions.md](domain_service_skeleton_instructions.md) — For backend services, control layer, and domain logic changes.
*   [ui_skeleton_instructions.md](ui_skeleton_instructions.md) — For frontend templates, Bulma layout, and HTMX interactivity.
*   [rbac_skeleton_instructions.md](rbac_skeleton_instructions.md) — For authorization, permission templates, roles, and domain template modifications.
*   [events_integration_skeleton_instructions.md](events_integration_skeleton_instructions.md) — For integrating other apps with the event tracking sub-application.
