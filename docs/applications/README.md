# Applications

Sub-application documentation lives here. Each entry follows this layout:

```
docs/applications/<app-name>.md                       ← Tier 1 anchor
docs/applications/<app-name>/                         ← Tier 2 deep specs
docs/applications/<app-name>/skeleton_instructions.md ← scan targets for task setup
```

See [../applications.md](../applications.md) for the full convention, the list of fundamental apps that stay at Tier 1/2, and the status of each application.
