# UI Test Plan: Session Close & Committing to Inventory Workflow

## Success Criteria

1. [x] Manager clicks 'Close & Commit Session'.
2. [x] System validates all part reconciliations are resolved.
3. [x] System updates intake session status to 'closed'.
4. [x] Items are registered into active inventory warehouse stock.
5. [x] Received counts are written back to procurement ShipmentLines.
6. [x] UI displays success message 'Session closed. Stock updated.'
