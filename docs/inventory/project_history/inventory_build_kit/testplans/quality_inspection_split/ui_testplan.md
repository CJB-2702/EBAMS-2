# UI Test Plan: Quality Inspection & Split Allocation Workflow

## Success Criteria

1. [x] Operator clicks 'Inspect & Split' on a line.
2. [x] UI displays numeric inputs for Good and Rejected splits.
3. [x] Operator inputs values that sum up to the total scanned quantity.
4. [x] System correctly creates/updates respective allocations for Good and Rejected.
5. [x] UI updates to reflect the split rows.
