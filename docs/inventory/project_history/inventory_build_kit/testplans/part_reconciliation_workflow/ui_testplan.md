# UI Test Plan: Part-Level Reconciliation Workflow

## Success Criteria

1. [x] Manager sees isolated view of discrepancies for a specific part.
2. [x] Manager can drag-and-drop or map unassociated/staged allocations to a specific shipment line.
3. [x] Manager can explicitly acknowledge and sign off on a short-shipment.
4. [x] Manager can quarantine overage items for later disposition.
5. [x] Manager can designate defective/rejected items.
6. [x] Intake session cannot be closed until all part reconciliation sessions are marked resolved.
