Get Started with EBAMS

Quick start guide to begin managing your assets

Prerequisites

code Python 3.11+

Python 3.11 or higher required

inventory_2 pip

Python package installer

merge Git

Version control system

Installation

1

Clone the repository

git clone <repository-url> cd ebams2
2

Create a virtual environment

# Create virtual environment python -m venv venv # Activate (Linux/Mac) source venv/bin/activate # Activate (Windows) venv\Scripts\activate
3

Install dependencies

pip install -r requirements.txt
4

Generate your environment file

python dev_tools/generate_env.py
5

Build the database and run the server

python manage.py migrate python manage.py seed_dev python manage.py runserver
info seed_dev creates development users and sample org/division/ownership data. The dev credentials it creates are written to a local, gitignored file rather than published here.

First login

Navigate to http://localhost:8000/ and sign in with a user created by seed_dev, or with your own Django superuser (python manage.py createsuperuser).

Full database reset

After any schema change, EBAMS uses a full reset rather than incremental migrations:

python dev_tools/delete_database_rebuild_models.py --seed
