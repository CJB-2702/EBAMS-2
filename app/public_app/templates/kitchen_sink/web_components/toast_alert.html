{# Event Script #} {# API & Documentation #}
API & Properties

HTML Attributes

  • type (string) - notification category. Maps to Bulma status classes. Options: success, danger, warning, info. Defaults to info.
  • dismiss-delay (integer) - delay in milliseconds before the toast auto-dismisses. Defaults to 3000. Set to 0 to disable auto-dismiss.

Public Methods

  • el.dismiss() - immediately slide out and remove the alert from the DOM.

Custom Events

  • toast-alert-dismiss - bubbles up when the alert is dismissed (manually or automatically).
{# Code Snippet #}
Template Code

Standard HTML Integration

<toast-alert type="success" dismiss-delay="3000">
  Asset has been updated successfully.
</toast-alert>

HTMX OOB Swap Response

Because the component automatically moves itself to document.body, you can return a toast element inside any HTMX response snippet to trigger a toast overlay:

<!-- Returned from POST /assets/edit -->
<toast-alert type="success">
  Permissions updated.
</toast-alert>
<div id="asset-form-fields">
  ... updated fields ...
</div>
