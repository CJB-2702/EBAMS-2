<collapsable-side-bar>

Collapsible application sidebar shell component.

{# Live Demo #}
Live Demo

Demo Menu

dashboardDashboard settingsSettings

Application Workspace

Click the toggle button (☰) inside the sidebar to collapse it. When collapsed, clicking anywhere on the sidebar strip will automatically expand it again.

{# API & Documentation #}
API & Usage

HTML Attributes

  • collapsed (boolean) - present when the sidebar is in its collapsed state. Can be toggled programmatically or via direct user clicks.

CSS Integration

To make the parent layout adjust seamlessly, style the parent container to observe the state of the component: 

.app-shell {
  display: grid;
  grid-template-columns: 220px 1fr;
  transition: grid-template-columns 0.18s ease;
}
.app-shell:has(collapsable-side-bar[collapsed]) {
  grid-template-columns: 40px 1fr;
}
