Design Intent & API

The <dual-list-box> is a light-DOM, style-only layout wrapper. It contains no internal JavaScript behavior. Its sole responsibility is rendering two lists side-by-side with vertical controls centered between them using CSS Grid: 

dual-list-box {
  display: grid;
  grid-template-columns: 1fr auto 1fr;
  gap: 0.75rem;
  align-items: center;
}

Slots

  • left - Content placed in the left-hand column (typically a <list-box>).
  • controls - Vertical stack of controls centered between columns.
  • right - Content placed in the right-hand column (typically a <list-box>).
{# Code Snippet #}
Django Template + HTMX Code

Because it is purely a styling layout, you can target the individual components inside it with standard HTMX calls: 

<dual-list-box id="groups-mgr">
  <list-box slot="left" id="groups-avail" label="Available">
    <select slot="options" multiple>...</select>
  </list-box>
  
  <div slot="controls">
    <button hx-post="/groups/add"
            hx-vals='js:{ids: listBox("groups-avail").selected()}'
            hx-target="#groups-mgr" 
            hx-swap="outerHTML">→</button>
    <button hx-post="/groups/remove"
            hx-vals='js:{ids: listBox("groups-held").selected()}'
            hx-target="#groups-mgr" 
            hx-swap="outerHTML">←</button>
  </div>

  <list-box slot="right" id="groups-held" label="Held">
    <select slot="options" multiple>...</select>
  </list-box>
</dual-list-box>
