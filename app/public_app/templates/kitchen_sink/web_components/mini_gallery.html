<mini-gallery>

Split-pane image viewer — large preview on the left, clickable file list on the right. Shadow-DOM encapsulated.

{# Live Demo #}
Live Demo
{# API & Documentation #}
API & Properties

Accepts files via the default slot — same slot format as <image-carousel>: one <img> per item, or an item with a data-filename attribute for a non-image placeholder entry. Clicking a row in the right-hand list swaps the left-hand preview.

Attributes

  • preview-height — CSS height of the preview pane (default 300, unit-less values are treated as px).

Settings menu

Hover the preview pane to reveal a gear icon offering Fit (whole image), Fill / crop, and Stretch — persisted to localStorage.

Custom events

  • mini-gallery-change — fired when the selected item changes; event.detail.index.
