<search-dropdown>

HTMX-powered typeahead dropdown component supporting native form binding.

Live Demo

Type to load matching options, then click an item to select it.

Selected form value: None

API & Properties

Form Associated Features

The component specifies static formAssociated = true. This lets it participate directly in standard HTML forms as a native input element (sending the chosen ID or slug value on form submit).

Supported Attributes (Passthrough to inner input)

  • placeholder - input placeholder text.
  • hx-* (hx-get, hx-post, hx-trigger, hx-target, hx-swap, hx-vals, hx-include) - all HTMX routing and request config attributes are parsed and forwarded to the inner search input automatically.

Public API

  • el.value (getter/setter) - the selected option value (e.g., database primary key ID).
  • el.name (getter) - the input field name used on form submission.
Template Code
<search-dropdown
  id="permission-picker"
  name="permission_id"
  placeholder="search permissions…"
  hx-get="{% url 'kitchen_sink_dummy_search_results' %}"
  hx-trigger="keyup changed delay:300ms, search">
</search-dropdown>
