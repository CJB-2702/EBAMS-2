help_outline

<info-popover>

Hover/click info bubble positioned relative to its trigger, detached to <body> so it is never clipped by an ancestor's overflow.

{# API & Documentation #}
API & Properties

Markup

Uses <detail>/<summary> child tags — deliberately not the native <details>/<summary> elements, chosen only for the semantic naming, not for accordion behavior.

  • <detail> — the trigger (icon or short text).
  • <summary> — the popover body content.

Attributes

  • direction — top (default) | bottom | left | right. Flips automatically if it would overflow the viewport.
  • hover — "true" (default) shows on hover/focus; "false" shows on click and closes on outside click / Escape.

Accessibility

Trigger is a real <button> (focusable, keyboard-activatable). Content has role="tooltip"/"dialog" as appropriate, linked via aria-describedby. Focus shows the popover in hover mode too.

{# Code Snippet #}
Template Code
<info-popover direction="top" hover="true">
  <detail><span class="icon has-text-info"><span class="material-icons">help_outline</span></span></detail>
  <summary>
    <p>Explanatory text…</p>
  </summary>
</info-popover>
