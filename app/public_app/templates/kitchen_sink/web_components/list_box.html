<list-box>

Light-DOM wrapper around select-multiple with integrated filter and actions.

Live Demo

[]
API & Properties

HTML Attributes

  • label (string) - optional <h4> heading text displayed above the list.
  • description (string) - optional helper subtitle text displayed below the label.
  • height (string) - option list height (CSS unit). Defaults to 12rem.

Slots

  • search - optional input used to filter options locally.
  • options (required) - target <select multiple>.
  • action - optional bottom action button. Defaults to a "Select all visible" button.

Public Methods

  • el.select - returns underlying select element.
  • el.items() - returns array of all option values.
  • el.selected() - returns array of selected option values.
  • el.selectAll() - selects all visible options.
  • el.clear() - deselects all options.

Custom Events

  • list-box-change - fired when option selection state changes. Contain values and labels.
  • list-box-scroll-end - fired when list option container is scrolled to the bottom (useful for infinite scroll pagination).
Template Code
<list-box id="avail" label="Available groups">
  <input slot="search" type="search" class="input is-small" placeholder="Filter...">
  <select slot="options" multiple>
    <option value="1">Group One</option>
    <option value="2">Group Two</option>
  </select>
</list-box>
