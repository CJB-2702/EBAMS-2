{# API & Documentation Section #}
Technical API Matrix

<image-carousel> Attributes

Attribute Type Default Description
preview-height String / Num 300 Height dimensions (accepts px, %, or vh units).
autoplay Boolean false Enables autoplay progression. Stops on hover.
autoplay-delay Number 4000 Interval timer delay in milliseconds.
loop Boolean true Loops past boundary index snaps.

<carousel-preview-items> Attributes

Attribute Type Default Description
for String (ID) (Required) Binds to the matching <image-carousel> element's ID.
size Number 50 Width and height of the preview blocks in pixels.

Public API Methods

  • carousel.next() - Move to next slide.
  • carousel.prev() - Move to previous slide.
  • carousel.goTo(index) - Jump directly to slide index (0-based integer).

Custom DOM Events

  • carousel-change - Emitted by carousel when slide index updates: { detail: { index: N } }.
  • carousel-items-changed - Emitted by carousel when slotted nodes load/modify: { detail: { items: [...] } }.

Image Gallery Layout
<image-carousel id="gallery-carousel" preview-height="300" loop>
  <img src="img1.jpg" alt="Description 1">
  <img src="img2.jpg" alt="Description 2">

<!-- Previews component connected to the gallery -->
<carousel-preview-items for="gallery-carousel" size="50"></carousel-preview-items>
