header_multi_select_card

Instead of a fixed title, the header is a selection menu — full-width, equal-width buttons spanning the top of the card. The button for the currently selected view gets is-primary; every other button sits dampened (is-light), the same visual weighting the footer uses for primary vs. secondary actions, just mirrored onto the top of the card. There is no secondaries column in the footer either — each action gets an equal share of the card's width via card-footer-uniform.

… panel content for the selected segment …

Use when a card's "sections" are mutually exclusive views of the same record rather than independent content beside a title — e.g. switching between Details / Permissions / History on the same role without leaving the card.
