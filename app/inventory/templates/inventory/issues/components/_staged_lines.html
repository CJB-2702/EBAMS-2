{% comment %} The plan being built — the right-hand column of the workspace. GROUPED BY DEMAND, not a flat list. A demand legitimately owns several lines: the container ran dry and the remainder came off another shelf, or three specific serials were picked. A flat list would show those as unrelated rows and leave the clerk adding up quantities in their head to answer "am I done with this demand". A GROUP WITH NO LINES IS A REAL STATE and renders as one — the demand is on the plan, nothing has been picked for it yet. No bin-less line is fabricated to stand in for it. NOTHING IS EDITED IN PLACE. A line is one fact — this much, off this shelf — so there is no "change the bin" and no "retype the quantity": delete the line and add it again. Every line is created in the location picker behind the `+` on the demand's header, which is where the quantity is decided. {% endcomment %}
