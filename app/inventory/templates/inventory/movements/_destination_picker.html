{% comment %} Client-side-only exception to this fragment's no-JS rule: the SVG map's shapes aren't real links (an SVG wrap around each shape proved unreliable across browsers), so clicking one can't do a plain page navigation. Filtering the already-rendered Location Directory rows by data-loc match is the only way to make that click do anything, so it's JS. The Map Area (XY) links and the clear-filter link below stay real hrefs (?loc=...), which is why the JS toggles inline display only and never touches the URL. {% endcomment %}
